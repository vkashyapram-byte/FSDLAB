💬 Viva Questions & Answers

1. What is full stack web development?

Full stack web development involves developing both the frontend (client-side user interfaces, styling, and interactions) and the backend (server logic, routing, REST APIs, and database integration) of a complete web application.

2. What is HTML5 and why is it used?

HTML5 is the modern revision of HyperText Markup Language. It provides semantic elements (<header>, <nav>, <article>, <footer>), enhanced form attributes, native multimedia (<audio>, <video>), and offline storage capabilities.

3. What is the purpose of the <!DOCTYPE html> declaration?

The <!DOCTYPE html> declaration informs the browser that the document is written in modern HTML5. This enforces standard-compliant rendering mode and prevents quirky legacy layout fallbacks.

4. What is the difference between ordered and unordered lists in HTML?

An ordered list (<ol>) numbers items sequentially to represent sequences, steps, or rankings. An unordered list (<ul>) presents items with bullet points without implied numerical order.

5. What is the role of a web browser in rendering HTML?

The browser parses the HTML into the Document Object Model (DOM) tree, parses CSS into the CSSOM tree, combines them into a render tree, computes dimensions and positions (reflow/layout), and paints pixels to screen.

6. What is Node.js and why is it needed in full stack development?

Node.js is an open-source, server-side JavaScript runtime built on Chrome's V8 engine. It allows developers to build backend web servers, microservices, and tooling using JavaScript across the entire stack.

7. What is the difference between frontend and backend?

Frontend is client-side code running in the user's browser for presentation and direct user interaction. Backend is server-side code handling business logic, user authentication, routing, and database persistence.

💬 Viva Questions & Answers

1. What is responsive web design?

Responsive web design is an approach where web layouts dynamically adjust to device screen widths, resolutions, and orientations to deliver optimal reading and interactive experiences.

2. What is the difference between Flexbox and Grid in CSS?

Flexbox is one-dimensional (content-first, handles single rows or columns). CSS Grid is two-dimensional (layout-first, handles rows and columns simultaneously).

3. What is a media query and how is it used?

A media query uses @media rules to apply CSS blocks conditionally when criteria such as viewport width, device orientation, or resolution are met.

4. What is the viewport and why is it important in responsive design?

The viewport is the visible rectangular viewing area of a browser. The viewport meta tag ensures mobile browsers match virtual layout pixels to actual device widths rather than zooming out.

5. What is the CSS box model?

The CSS box model dictates how elements render with content, padding, border, and margin areas.

6. How does display: flex differ from display: block?

display: block stacks items vertically taking 100% parent width. display: flex arranges items along main and cross axes with dynamic alignment, spacing, and sizing.

7. Why is responsive design important in modern web development?

It provides consistent usability across smartphones, tablets, laptops, and ultra-wide desktops while boosting search engine ranking and user retention.

💬 Viva Questions & Answers

1. What is the DOM in web development?

The Document Object Model (DOM) is an API and hierarchical tree representation of an HTML document in memory that exposes elements as controllable nodes.

2. What is the difference between getElementById and querySelector?

getElementById(id) takes a simple ID string and is faster for single element access. querySelector(selector) accepts any valid CSS selector string.

3. How does createElement work in JavaScript?

document.createElement(tagName) creates a new HTML node in memory. It must be attached to the visible document tree using appendChild() or insertBefore().

4. What is an event listener and why is it used?

An event listener registers an event callback on a targeted element to react to user interactions like clicks, inputs, and keypresses.

5. What is the difference between innerHTML and textContent?

textContent sets or returns plain text without parsing markup (immune to XSS). innerHTML parses HTML tags within strings.

6. How can you remove an element from the DOM?

In modern JavaScript, invoke node.remove() directly on the element, or parentNode.removeChild(node).

7. Why is JavaScript important in frontend development?

JavaScript introduces asynchronous connectivity, client validation, dynamic DOM rendering, and interactive responsiveness.

💬 Viva Questions & Answers

1. What is form validation and why is it important?

Form validation verifies that submitted data conforms to expected formats (non-empty, valid email, minimum length) before processing to ensure data integrity and avoid unnecessary server requests.

2. What is the difference between client-side and server-side validation?

Client-side validation runs in the browser giving instant feedback. Server-side validation runs on the backend and is mandatory for security as client checks can be bypassed.

3. What is a regular expression and how is it used in JavaScript?

A regex is a character sequence describing a search pattern. In JS, patterns like /^[^\s@]+@[^\s@]+\.[^\s@]+$/ are matched with .test() to validate string structures.

4. What is the preventDefault method used for?

event.preventDefault() stops the default browser action, such as halting form reloads so custom JavaScript validation can execute.

5. How can you check if an input field is empty using JavaScript?

By checking input.value.trim().length === 0 or input.value.trim() === ''.

6. What are HTML5 built-in validation attributes?

Attributes like required, minlength, maxlength, pattern, and types like email, number, and url.

7. Why should client-side validation not replace server-side validation?

Because client-side validation can be disabled in DevTools, disabled in browser settings, or bypassed using HTTP tools like Postman.

    💬 Viva Questions & Answers

    1. What is authentication and how is it different from authorization?

    Authentication confirms identity ('Who are you?'). Authorization determines permissions ('What resources are you allowed to access?').

    2. What is JWT and what are its three parts?

    JSON Web Token is an open standard compact token consisting of three base64URL parts separated by dots: Header (algorithm & token type), Payload (claims/data), and Signature (HMACSHA256 hash using secret key).

    3. Why is password hashing necessary?

    Storing plain-text passwords exposes user credentials to catastrophic breach if databases are compromised. One-way cryptographic hashes prevent reversing stored secrets.

    4. What is bcrypt and how many salt rounds are typically used?

    bcrypt is an adaptive password hashing function incorporating cryptographic salts to defend against rainbow table attacks. Standard industry practice uses 10 to 12 salt rounds.

    5. What is a middleware function in Express.js and how is it used for route protection?

    An auth middleware inspects the Authorization: Bearer <token> header, verifies token validity using jwt.verify(), attaches decoded user identity to req, and calls next() to permit route entry.

    6. What is the difference between stateful and stateless authentication?

    Stateful authentication stores session IDs in server memory/Redis requiring state lookup on every request. Stateless JWT authentication embeds signed claims in the token itself, verified without server-side state lookup.

    7. What is the purpose of the .env file and the dotenv package?

    It isolates sensitive credentials (database connection strings, secret keys, port numbers) outside version control into process.env.

    import { useEffect, useState } from 'react';
import axios from 'axios';

function StudentList() {
  const [students, setStudents] = useState([]);
  const [loading, setLoading] = useState(true);

    })
    .then(res => {
      setStudents(res.data);
      setLoading(false);
    })
    .catch(() => setLoading(false));
  }, []);

  if (loading) return <p>Loading students...</p>;

  return (
    <div>
      <h2>Enrolled Students</h2>
      <ul>
        {students.map(s => (
          <li key={s._id} style={{ padding: '8px', borderBottom: '1px solid #ccc' }}>
            <strong>{s.name}</strong> - {s.dept} (Marks: {s.marks})
          </li>
        ))}
      </ul>
    </div>
  );
}
