# Full Stack Development Laboratory Manual (4CSPL2021)

A responsive, interactive lab manual reader for CMR University's **4CSPL2021: Full Stack Development** course (Instructor: Rohit Kumar).

🔗 **Live Deployment**: [https://fsdlabb.vercel.app](https://fsdlabb.vercel.app)

---

## 📑 Included Experiments

1. **Lab 4: Form Validation Using JavaScript**
   - Client-side validation for Name, Email, Password, Confirm Password, and 10-digit Phone Number.
   - Interactive live validation simulator.
   - Complete viva questions and answers.

2. **Lab 5: React - Basic Application Using Components**
   - React environment setup using Vite.
   - Component-based architecture with `StudentCard` and props.
   - Real-time interactive props simulator.
   - Complete viva questions and answers.

3. **Lab 6: React - State Management and Event Handling**
   - State management with the `useState` hook.
   - Interactive live Counter and dynamic To-Do List simulator.
   - Complete viva questions and answers.

4. **Lab 7: React - API Integration Using Fetch and Axios**
   - Fetching REST API data from JSONPlaceholder with `useEffect` and `axios`.
   - Handling loading state and error states.
   - Live interactive API simulator with live JSONPlaceholder requests and error handling simulation.
   - Complete viva questions and answers.

5. **Lab 8: Node.js - Creating a Basic HTTP Server**
   - Built-in `http` module server handling `GET /`, `GET /about`, and `POST /data`.
   - Parsing JSON request bodies via data stream events and returning JSON responses with 200/404 HTTP status codes.
   - Live interactive HTTP server console with Postman simulator.
   - Complete viva questions and answers.

---

## 💻 Tech Stack & Features
- **Frontend**: HTML5, Modern CSS (`color-scheme: light dark`), Vanilla JavaScript
- **Features**:
  - 5-Button quick navigation (Lab 4, Lab 5, Lab 6, Lab 7, Lab 8)
  - One-click code snippet copying
  - Font size adjustment (`A+` / `A−`)
  - Dark / Light mode toggle
  - Print / PDF export layout
  - Interactive live simulators for each lab
- **Deployment**: [Vercel](https://fsdlabb.vercel.app)
